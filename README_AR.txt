HR Numbers - PWA v1

هذه نسخة ويب تجريبية مهيأة للآيفون.
رمز الدخول التجريبي: 1234

المزايا:
- البحث برقم الموظف أو الاسم.
- عرض بيانات الموظف.
- تسجيل: غياب / إذن خروج / إجازة / استقالة.
- حفظ المعاملات داخل متصفح الجهاز باستخدام Local Storage.
- دعم الإضافة إلى الشاشة الرئيسية عند تشغيل الموقع من HTTPS.

مهم للتجربة على iPhone:
يلزم رفع محتويات هذا المجلد إلى استضافة HTTPS (مثل GitHub Pages أو Netlify أو Cloudflare Pages).
بعد فتح الرابط في Safari: مشاركة > إضافة إلى الشاشة الرئيسية.

ملاحظة أمنية:
رمز 1234 مجرد رمز تجريبي وليس نظام تسجيل دخول آمنًا للإنتاج.
